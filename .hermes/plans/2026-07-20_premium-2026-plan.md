## 1. The ultra-premium upgrade layers (2025–2026 trends)

### A. Surface depth & material (the "wow" base)
- **Concentric grain + aurora**: add a near-invisible SVG/noise grain layer + a second slower aurora blob to `.bg-mesh` so surfaces read as *material*, not flat.
- **Layered glass (v3)**: cards get a 1px top highlight (already there) **plus** a subtle inner bottom shadow and a 0.5px outer ring for "cut from glass" edge definition.
- **Soft radial spotlight** that follows pointer on hero/destination cards (CSS only, `radial-gradient` at mouse via a tiny JS-free trick is not possible → use a static top-left light + hover-amplified glow).
- **Gradient hairline borders** on premium cards using `border-image` / masked pseudo-element (champagne→brand) instead of solid `#soft`.

### B. Motion that feels alive (but calm)
- **Scroll progress rail**: a 2px gradient bar under the navbar tracking `scrollTop/scrollHeight` (iOS Safari safe, reduced-motion off).
- **Scroll-aware navbar**: navbar subtly shrinks padding + lowers blur after 120px scroll (class toggled from a tiny effect hook already in App — additive, optional).
- **Entrance choreography**: stagger already exists; refine to a softer `ease: [0.16,1,0.3,1]` (expo-out) and add a 6px→0 translate so cards "settle".
- **Magnetic hover** on icon tiles (existing `--ease-spring` is good; add a faint scale 1.01 + ring pulse).

### C. Typography refinement (already strong → make it editorial)
- **Display optical sizing**: push `--font-display` `font-variation-settings: 'opsz' 72` on hero; tighten `letter-spacing` to `-0.03em` on `h1/h2`.
- **Drop-cap / eyebrow rhythm**: section eyebrows get a 2px champagne tick before the label; more breathing room (`margin` between eyebrow and title).
- **Numerals**: ensure `tabular-nums` on all metric/ICD/count strings (mostly done; extend to `.chip-count`, `.search-result-count`).
- **Reading measure**: cap long-form modal copy at `64ch` (currently 68ch) and increase line-height to 1.7 for body.

### D. Touch & reachability (the only hard gap)
- `.navbar-action-button`: min-height **44px** on all viewports (desktop currently 32px).
- `.catalog-sort-chip`: min-height **44px**, padding tune (currently 17px tall — fails HIG).
- `.navbar-brand`: increase hit area to ≥44px (wrap mark+copy, padding).
- `.mobile-bottom-item`: ensure ≥44px tap zone (already ~ok; verify label+dot).
- Keep visual size small via padding/negative-margin tricks so **look** stays compact while **hit area** is 44px.

### E. Delight details (critic-level finishing)
- **Focus rings**: 2px champagne ring + 4px soft glow (currently inherits generic) for keyboard users.
- **Selection**: champagne tint (already). Extend to inputs.
- **Empty states**: add a soft radial glow behind the icon + a gentle float animation (reduced-motion safe).
- **Scrollbar**: style the thin premium scrollbar (webkit + firefox) in brand tint.
- **Theme transition**: animate `background-color`/`color` on `html` for a 240ms cross-fade when toggling dark/light (currently instant).
- **Command cards shimmer**: slow to 2.2s and soften gradient so it reads as "premium loading" not "cheap skeleton".
